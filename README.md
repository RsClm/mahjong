# 麻将助手 Web

一个可部署到 GitHub Pages 的手机端麻将助手。应用在浏览器本地运行，支持手动录入手牌/鸣牌、计算普通麻将向听数、提示听哪些牌，并给出切牌建议。

## 功能

- 万、筒、条、字牌录入。
- 支持吃、碰、杠等已鸣牌，把固定面子计入分析。
- 支持非 13/14 张输入，适合边录入边查看建议。
- 显示当前向听、听牌、有效进张和切牌排序。
- 支持拍照/上传，照片只在本机浏览器预览，并进入人工校正流程。

## 本地运行

```bash
npm install
npm run dev
```

## 测试与构建

```bash
npm test
npm run build
```

## GitHub Pages 部署

1. 把项目推送到 GitHub 仓库的 `main` 分支。
2. 在仓库设置中打开 Pages，Source 选择 GitHub Actions。
3. `.github/workflows/deploy.yml` 会自动运行测试、构建并发布。
4. 发布完成后，用手机访问 GitHub Pages 提供的 HTTPS 地址即可。

## 拍照识别说明

为了满足免费、无需常驻后端机器的部署要求，当前版本不会把照片上传到云端，也不会保存图片。静态站点无法安全保存云识别 API 密钥，因此第一版提供本地照片预览和可替换的识别抽象，用户可以边看照片边校正手牌。

识别模块位于 `src/vision/recognizeTiles.ts`，后续可以替换为浏览器端模型、模板匹配，或接入有免费额度的 serverless API。

## 规则范围

- 按普通麻将 4 面子 1 雀头计算，并支持七对子；不包含番种、十三幺、花牌、宝牌和地方役种。
- 支持摸牌前（3k+1，如 13 张）与摸牌后（3k+2，如 14 张）两种形态：13 张给出经典向听与听牌，14 张给出切牌建议与切后听牌。
- 杠按一组面子计入，总张数上限随杠数 +1；向听计算不区分杠的类型。
